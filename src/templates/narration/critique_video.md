## Instructions

Write narration that:
1. Frames each finding as a growth opportunity, never a problem
2. Uses constructive language: "enhance", "strengthen", "refine", "could benefit from"
3. Provides context for WHY the improvement matters (user impact, business value)
4. Matches the visual content being shown in this segment
5. Maintains an expert consultant tone — knowledgeable but supportive

## Anti-Patterns — Do NOT:
- Use negative words: problem, issue, broken, missing, error, wrong, bad, fail
- Sound condescending or critical
- List findings without context
- Start with "In this section" or "Now we see"

Output ONLY the narration text — no JSON, no markdown formatting, just the spoken words.
Do NOT include any preamble such as "Here is the narration:" — start directly with the spoken words.
